# Revelation RT v7.1 手持光源近墙修正

目标为 Minecraft 1.21.1 Fabric / Iris 1.8.14-beta.1。本轮构建交付，由用户运行游戏验收。

## 原因与修正

v7 将手持光源固定在视图坐标 `(±0.35, -0.20, -0.55)`，没有检查这个位置是否已进入方块。墙距离视点不足约半格时，光源可能进入墙内，表面朝向计算会变成背光，阴影射线也可能被墙挡住。

v7.1 在每帧的 `deferred18` 阶段计算左右手光源位置，按附近模型包围盒、镂空纹理体积和玻璃板连接形状检查碰撞。接触墙面时，将光源退回视点与墙之间的可用空间，并同步收缩软阴影采样范围。普通表面、半分辨率灯光与透明表面共用同一份位置数据。

没有碰撞时保留原手持偏移；没有局部捕获数据的 Legacy GI 档位使用视点光源。位置仍为近似手持代理，未追踪模组自定义的手臂与物品动画。

近距离阴影检查的距离门槛从 0.15 格降至 0.02 格，继续保留墙体和薄块的遮挡，没有通过关闭阴影来恢复照明。

## 验证

- 使用已交付 v7 的原手持光照函数作对照：同一面距视点 0.3 格的墙上，旧函数 RGB 为零，修正后恢复照明，光源保持在墙外；墙背面的采样仍被遮挡。
- 检查 0.005–1.2 格的靠墙距离、两侧墙、主手方向切换、仅副手发光、关闭发光物品、俯仰和偏航变换、负坐标、染色玻璃及连接/孤立玻璃板。
- 检查原有选框、滤色、多层玻璃、孔洞阴影、局部灯光缓存与后期处理的回归测试。
- `compile-v71.json` 记录预设及特性组合的 GPU 编译/链接检查；`physical-probes-v71.json` 记录行为结果；`iris-metadata-v71.json` 使用当前安装的 Iris 解析器。
- `handheld-position-v71-timing.json` 记录每帧一次、两个光源位置计算的 GPU 时间查询。首次测试中空场景与近墙场景中位数约为 0.0043 / 0.0048 毫秒；这不是 Minecraft 整帧 FPS。

这些是离线验证，没有启动新的 Minecraft 客户端，也没有把离线结果当作游戏画面或 FPS 验收。

## 安装与测试

选择 `Revelation-RT-v7.1-HandheldFix.zip`。安装时继承当前 v7 的设置，方便在同一视角与画质下比较。

手持灯笼或火把，缓慢靠近石墙、左右两侧墙和台阶；检查照明是否仍突然消失。然后切换副手并转动视角，确认修正对两只手都生效。可隔着玻璃和活板门检查透光、滤色及遮挡是否仍正常。

局部捕获范围仍为相机周围 64³ 格。Distant Horizons、Voxy、Super Resolution 和自定义动画的游戏运行集成本轮未验收。保留 HaringPro 原署名与 Apache-2.0 许可。

最终版本通过 546 项 GPU 编译/链接检查、410 项行为检查及已安装 Iris 的元数据和工作组解析。新增计算程序使用 Iris 接受的 `ivec3(1,1,1)`，每帧一个工作组处理两只手。测试源码、原 v7 对照函数、完整报告和时间查询结果随包保留。
