# Revelation RT v9.3：光源调色与手电筒

2026-10-27。基于用户确认的 v9.2 单投影阴影。

## 设置入口

光影设置主界面 → **光源与手电筒**。也可从“光照”页面进入。这里有三个页面：

| 页面 | 设置 | 行为 |
| --- | --- | --- |
| 方块光源设置 | 方块光源亮度 | 默认 1；0 关闭方块发光，支持提高强度。独立于手持光源。 |
| 方块光源设置 | 自定义方块光色、红/绿/蓝 | 关闭自定义时保留各类光源原色；开启后用 RGB 统一调色，照明和自发光同步调整。 |
| 手持光源设置 | 手持光源亮度 | 默认 0.5；0 关闭，控制火把等手持照明以及手电筒的强弱。 |
| 手持光源设置 | 自定义手持光色、红/绿/蓝 | 关闭时保留物品原色；开启时使用 RGB，独立于方块光色。 |
| 手电筒设置 | 手持火把变为手电筒 | 默认关闭。开启后普通、灵魂、红石火把改为跟随视角的聚光照明。 |
| 手电筒设置 | 光束张角 | 默认完整张角 40°，越小光斑越窄。 |
| 手电筒设置 | 光束边缘柔和度 | 默认 0.2；0 是硬边，增大后边缘渐变更宽。 |
| 手电筒设置 | 照射距离 | 默认 24 格，可设 6～30 格；仍有正常距离衰减。 |

**白色手电筒示例**：开启手电筒模式；开启自定义手持光色，RGB 都设为 1；手持亮度可先设为 1，再按场景调整。手电筒模式只改变火把类，手持灯笼、发光方块等保持原有全向照明，主副手均支持。

RGB 和亮度、手电筒开关不属于画质档参数，切换极高/高/低不会覆盖这些个人设置。默认不开启自定义色和手电筒，保留 v9.2 的原色与单投影行为。

## 实现与性能

- 每盏灯的一次稳定阴影投影保持不变。手电筒是视角空间的平滑角度遮罩，光斑中心对准准星；遮挡仍使用原有经过碰撞约束的手持位置。它不是新的道具模型。
- 光束外先返回，不进行阴影射线追踪；光束内仍只追踪一次。没有新增渲染阶段、历史纹理或随机采样。
- 保留墙体遮挡、染色玻璃吸收与透射。手电筒是表面聚光照明，本版没有新增空气中的体积光柱。
- 方块自发光与 GI 的发光回退一同调色/调强度，避免直接光已经变红，反弹光却继续从白色发光面取样。
- 手持光源不再乘以方块亮度，调暗方块不会同时调暗火把。
- 单独映射三类火把物品 ID，避免同组的灯笼、营火和红石块误入手电筒模式；不修改原版物品行为。

照射距离变长会改变可见区域的追踪负载。实际 FPS 与画面由用户测试，本版不启动或修改游戏实例。

## 验证

- `light-controls-v93.json`：真实 GPU 光照函数上的 21 项检查，覆盖颜色/亮度独立性、零亮度、线性强度、光束中心/侧后方、范围、宽度、柔边、双手、仅三类火把、实际射线计数、墙体与染色玻璃。
- `shadow-projection-v93.json`：复查原单投影、活板门开孔、独立 CPU 投影与 32 帧稳定性。
- `physical-probes-v93.json`：多光源、开孔、玻璃、手持碰撞和缓存回归。
- `compile-v93.json`：六档与自定义光色、手电筒、材质包颜色采样、亮度为零等分支编译/链接。
- `iris-metadata-v93.json`：本机 Iris 的参数识别、页面入口、合法值、质量档切换不重置调光设置，以及火把专用物品映射。
