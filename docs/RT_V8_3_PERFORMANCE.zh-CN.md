# Revelation RT v8.3：帧率与物理光照模型

目标：Minecraft 1.21.1 Fabric / Iris 1.8.14-beta.1。2026-10-27。
上一版：`docs/RT_V8_2_SEAMS.zh-CN.md`（多灯接缝回归 + 启动链接时间）。

## 1. 帧率：把“每像素每盏灯都打一条阴影射线”改成默认不打

v8.2 的默认档在 12 盏灯、全分辨率、4 次面光采样下，每像素最多要跑
`灯数 × 采样数` 条可见性射线，每条射线是一次最多 192 格的场景网格 DDA（含形状求交）。
这就是帧率掉到个位数的原因：**代价与灯数和采样数乘积成正比**，而屋子里的灯越多越慢。

v8.3 的做法：

| 档 | 局部光可见性 | 每像素代价 |
| --- | --- | --- |
| 默认（本版） | 解析（用真实方块光照图的遮挡） | 每盏候选灯 ~30 ALU，无射线 |
| 光线追踪档 | 场景网格 DDA，可选每帧单采样时间累积 | 每盏被追踪灯 ~一次完整 DDA |

关键实现点：

- `RT_LOCAL_TRACED_SHADOWS` 开关控制是否发射可见性射线。**关闭时没有“追踪预算”**：
  所有被图块掩码选中的灯都按解析核积分，因此既没有截断、也没有亮度带。
- 打开时才有每像素预算 `RT_LOCAL_MAX_TRACED`（默认 4）+ 相对截断
  `RT_LOCAL_IMPORTANCE_CUTOFF`（默认 2%，相对于最强灯）；排序在寄存器里完成，
  不落入局部内存（`#pragma optionNV(unroll none)` 会把索引数组溢出到 local memory，
  实测比它省下的射线更贵）。
- `RT_LOCAL_TEMPORAL_SHADOWS`：每帧只在发光圆盘上取 1 个旋转样本，由 TAA/SVGF
  在时间上积分半影，代替每帧 4~16 个样本。
- 体积雾同样改为解析（`RT_LOCAL_VOLUME_SAMPLES 2` + `RT_LOCAL_VOLUME_LIGHT_CAP 2`）。

### 实测（RTX 5060 Laptop，`validation/gpu-bench.json`）

受控场景：12 盏灯全部在范围内、相机与接收面之间有一面石墙（最坏情况），
960×540，20 帧取 3 批计时最小值。

| 模式 | 表面局部光 | 局部体积雾 |
| --- | --- | --- |
| 解析（默认） | 182 ms | 385 ms |
| 追踪（每像素 4 盏） | 2025 ms | 2631 ms |
| 加速比 | **11.1×** | **6.8×** |

说明：这是**内核级**计时（只含这两个 pass），同一 harness 的空内核地板是 7–44 ms，
绝对毫秒被低占用率放大，请把**倍数**当作游戏内的预期，不要把毫秒直接换算成 FPS。
游戏内帧率由用户验收：这版把局部光那一项从“每像素多条 DDA”降到“每像素几十次算术”，
是唯一能解释并消除个位数帧率的结构性改动。

## 2. 光照模型：从“手调常数”换成有限面积光源 + 色温

旧核（v8.2）：`1.25 · window² / max(d² + r², 0.25)`，颜色是三个手写 RGB 常量，
1.25 与 0.25 都是拟合出来的魔数。

新核（`lib/lighting/Emitters.glsl`）：

```
L      = Φ / (π² r²)          朗伯圆盘的出射辐亮度
Ω      = π r² cosθ_s / d²     接收点看到的立体角
E      = L · Ω · cosθ_r       辐照度
⇒ 核   = cosθ_s · cosθ_r / (π · max(d², r²))
```

- `max(d², r²)` 是**有限光源**的正确远场/近场极限：像素落在灯内部时辐照度饱和，
  不再像 `1/(d²+r²)` 那样任意截断，也不会发散。
- `window`（有限作用半径）在灯的 range 处值与斜率都归零，所以它不会在墙上画出边。
- 颜色：`RTBlackbodyChroma(色温)` 用 Planchian 轨迹拟合（Kim 2002）给出黑体色度，
  火焰类按真实燃烧温度取色（火把 1900 K、灯笼 2200 K、岩浆/营火 1500 K、
  荧光石 3000 K、海晶灯/末地烛 5600 K），非热发光体（灵魂火、红石）保留实测光谱色。
- 通量 `RTEmitterFlux` 保持旧版的相对亮度量级，所以观感不会整体跳变，变化的只有
  **光谱分布**与**距离响应形状**。

注意 `rPI` 在本包里是 `1/π`（不是 π）。首版新核写成了 `rcp(rPI * d2)`，等于把亮度放大
π²≈9.87 倍；已修正为 `rPI * rcp(d2)`，并由 `dense-lights` 的独立 CPU 参考逐像素校验
（修正前该测试报固定比例 0.1013 = 1/π²，修正后误差 0）。

## 3. 想更接近 60 FPS 时的调节顺序

1. 光影设置 → 画质档：`低`（关 GI、关体积雾、1024 阴影）。
2. 高级 → 光线追踪：确认 `RT_LOCAL_TRACED_SHADOWS` 关闭（本版默认关闭）。
3. 仍不足再依次降：`SSILVB_SAMPLE_COUNT` → 8、`SSRT_MAX_SAMPLES` → 8、
   `CLOUD_LOW_SAMPLES_MAX` → 32、`shadowMapResolution` → 1024。
4. 想用追踪阴影：打开 `RT_LOCAL_TRACED_SHADOWS` + `RT_LOCAL_TEMPORAL_SHADOWS`，
   并把 `RT_LOCAL_MAX_TRACED` 设为 1~2、`RT_LOCAL_HALF_RES` 保持开启。
