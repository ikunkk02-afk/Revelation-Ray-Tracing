# Revelation RT v7 测试说明

目标：Minecraft 1.21.1 Fabric，Iris 1.8.14-beta.1，OpenGL 4.6。
本轮按要求构建交付，由用户启动游戏测试；没有启动 Minecraft。

## 修改

- **选框白边**：原 Basic 路径只写材质的两个通道，选框还会参与普通表面的光照。现在明确写满四个通道，使用独立的选框材质，排除灯光、反射与发光；在调色和锐化后保留深灰描边。仍可在选框颜色设置中调整 RGB，默认均为 0.05。
- **后期稳定性**：修正 CAS 在纯黑处可能出现的零除和非有限值，将锐化结果限制在邻域实际色值内，减少高反差边缘的过冲。
- **局部灯光性能**：默认档与流畅档在半宽、半高的缓存中计算粗糙不透明表面的局部漫反射，按接收面平面距离和法线重建。覆盖不足、明显的阴影/颜色跳变会回退到原分辨率追踪；光滑或金属 PBR、手部和透明表面保留原有分辨率。缓存每帧重算，不增加历史拖影；无灯光的屏幕分区直接跳过重建。
- **染色玻璃**：改用吸收系数插值与 Beer 定律，减少透射光中混入的中性白色。默认滤色强度从 0.65 调至 0.85；多层玻璃继续累计吸收，薄玻璃板按实际厚度透光。太阳、局部光、体积散射和可见玻璃使用相同的光学参数。
- **玻璃运算成本**：预计算 16 色吸收系数；遍历时累计光学厚度，结束时再求透射，避免逐格重复颜色转换、对数和指数运算。

## 安装与对比

选择独立文件 `Revelation-RT-v7-Spectral.zip`，默认使用“RT - 参考效果 / 孔洞投光”。旧 v6 保留。
新包的设置文件仅继承用户已打开的 `RP_SUPPORT=true` 和 `MOD_BLOCK_SUPPORT=true`，没有沿用旧质量参数。

若希望进一步减轻负担，切换“RT - 流畅优先”。若要检查极小光斑、密集细孔或高频阴影，可在光线追踪设置中关闭“局部漫反射半分辨率”做对比。超高与电影档默认关闭这一优化。

建议在同一坐标、视角、分辨率、材质包和光源下比较：

1. 昏暗洞穴中瞄准方块，检查选框是否仍发白或出现辉光。
2. 白色光源外包红、蓝、青色玻璃，检查附近墙面、地面和光束颜色；增加第二层玻璃检查叠层滤色。
3. 普通玻璃与玻璃板对比，确认薄玻璃板透光更强。
4. 用活板门包围光源，检查孔洞投影；开关半分辨率对比细节与 FPS。
5. 等待曝光与区块加载稳定后观察帧时间，避免把不同场景的瞬时 FPS 当成同条件对比。

## 验证与边界

`validation/compile-v7.json` 记录预设与特性组合的 GPU 编译/链接结果。
`validation/physical-probes-v7.json` 记录真实着色器的离线行为测试，包括孔洞几何、玻璃吸收、选框输出、后期纯黑稳定性和灯光缓存。
`validation/iris-metadata-v7.json` 使用本机已安装 Iris 的解析器检查参数和元数据。
`validation/performance-v7-local.json` 使用 GPU 时间查询测量受控接收面上的局部灯光完整缓存路径与原分辨率路径；这不是 Minecraft 整帧耗时，也不能直接换算为游戏 FPS。

局部几何捕获范围仍为相机周围 64³ 格，每个屏幕灯光分区最多选择四个光源，最多登记 256 个局部光源。半分辨率重建仍可能弱化小于采样间距的细光斑，开关保留用于质量取舍。屏幕空间反射、间接光与离屏信息仍有原实现的限制；本包不是硬件 RTX 路径追踪。

本轮没有验证游戏内画面、实际 FPS、Distant Horizons、Voxy 或 Super Resolution 的运行集成。所有游戏效果以用户测试为准。保留原作者 HaringPro 的 Apache-2.0 许可与署名。

## 本次离线结果

RTX 5060 Laptop / OpenGL 4.6：522 项编译/链接检查、393 项行为检查通过；遮挡与透射测试累计 622592 条查询射线，其中孔洞测试为 98304 条。已安装的 Iris 解析器检查 371 份着色器源文件通过。

在 256×256 的受控粗糙接收面、一个暖色局部光源（kind 7）、无额外遮挡的场景中，比较同一 v7 光照函数的原分辨率路径与缓存完整路径：九次 GPU 时间查询的中位数分别为 0.136896 ms 和 0.051584 ms，约 2.65 倍；最大 RGB 绝对误差约 0.000390。无光源分区中位数分别为 0.016832 ms 和 0.016064 ms。测试包含缓存生成与重建，不包含 Minecraft 其余渲染开销；不能据此推算整包 FPS。
