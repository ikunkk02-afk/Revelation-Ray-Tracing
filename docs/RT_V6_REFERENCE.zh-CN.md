# Revelation RT v6：参考光照与流畅档

目标：Minecraft 1.21.1 Fabric / Iris 1.8.14-beta.1，RTX 5060 Laptop。
原作者 HaringPro，Apache-2.0。构建日期：2026-10-26。

本轮以用户提供的四张其他光影截图作为目标：暖色手持火把、带半影的灯笼、凹槽中的光照与阴影，以及从外壳孔洞向外投射的光斑和淡光束。前三张截图时间段的日志显示使用 iterationRP Alpha 0.8.26 hotfix.zip。此次按用户要求只构建和离线验证，未启动 Minecraft，未宣称已经达到或超过参考图的游戏画面及 FPS。

## 直接测试

在 Iris 中选择 **Revelation-RT-v6-Reference.zip**。

| 档位 | 用途与预算 |
|---|---|
| **RT - 参考效果 / 孔洞投光** | 默认。4 个局部阴影样本，4 个手持阴影样本，1 路径 / 1 次间接反弹，1 个反射样本，24 步屏幕射线；半分辨率局部体积光每像素取 4 个点、查询最近相关的一盏灯。 |
| **RT - 流畅优先** | 2 个局部 / 手持阴影样本，16 步屏幕射线，关闭新增的人工灯体积光；保留精细孔洞遮挡、玻璃透射和分层加速。 |

首次加载默认值已对齐参考档，不依赖仅命名为 Default 的配置自动替用户应用参数。如果帧率不足，先切流畅档，再进行同位置对比。

## 这一版实际修改

1. **合并光线查询。** v5 对同一灯光段先查不透明遮挡、再单独遍历玻璃；v6 在一次遍历中同时查询模型、孔洞和玻璃。多层玻璃先累积光学厚度，最后统一求指数透射。
2. **分层空区域跳过。** 在 `shadowcomp` 阶段将 64³ 局部数据汇总为 16³ 个空间分块。每个 4³ 格分块保存两组 64 位掩码，分别描述遮挡和玻璃。射线跳过完全空的分块，只在有数据的格子读取细节。孔洞精度仍为原版的 1/16 格。
3. **更明确的孔洞投影。** 发光面尺寸成为可调项，参考档取 0.65 倍。缩小发光面让活板门等外壳后的光斑更清晰，仍由实体/镂空几何决定投影，不使用屏幕上的固定图案。
4. **局部人工灯体积光。** 在现有半分辨率雾中加入局部灯的遮挡和玻璃透射，形成受外壳孔洞约束的淡光束。用时间重建补足低采样，并降低亮度变化时的历史权重，以加快开关灯响应。
5. **修正末端漏光。** 只有发光方块本身可免于遮挡自身发出的光；射线终点格内的石墙、门或活板门仍需检查。手持光不再因为终点位于同一格而直接忽略该格的遮挡。
6. **保留前版光学。** 暖光按距离衰减、源尺寸软阴影、玻璃厚度吸收、双界面折射、Fresnel / GGX 反射与局部灯高光继续保留。太阳和天空的生产入口保持独立。

## 离线性能实测的含义

在本机 RTX 5060 Laptop / OpenGL 上，使用 GPU `GL_TIME_ELAPSED` 测量生产可见性函数。每个场景 262,144 条射线，预热后交错测量新旧路径各 9 次，以中位数比较；新路径计入每帧一次的加速数据生成开销。基准旧函数与已交付 v5 的文件逐字节一致，光线结果也进行逐项比较。

| 受控场景 | v5 两次遍历 | v6 含分层数据生成 | 大约加速 |
|---|---:|---:|---:|
| 空旷房间 | 1.14 ms | 0.50 ms | 2.27 倍 |
| 狭窄洞穴 | 0.99 ms | 0.76 ms | 1.30 倍 |

精确数据及每次样本见 `validation/performance-v6.json`。**这些是局部射线内核耗时，不是整个光影包的帧时间，更不能换算为实际游戏 FPS 提升倍数。** 新增体积光也有成本，整体帧率需要在游戏中确认。

## 已做校验

- 七个档位和关键功能组合的真实 GPU 编译/链接；准确数量见 `validation/build-v6.json`。
- 378 项 GPU 行为检查，包括 622,592 条孔洞/一致性测试射线、终点格遮挡、GPU 占据掩码、玻璃吸收和人工体积光的遮挡/关闭/染色检查。
- 本机安装的 Iris 1.8.14-beta.1 的元数据与选项解析。
- ZIP CRC、包内逐文件校验、报告与当前源码摘要一致性，以及安装目录中的 ZIP 哈希校验。

`validation/v6-aperture-probe.png` 是生产遮挡函数生成的受控孔洞探针图，**不是 Minecraft 游戏截图**。

## 建议你优先看四个场景

1. 手持火把绕石块缓慢移动，观察暖光渐变、阴影边缘和拐角漏光。
2. 洞中放灯笼，观察地面光池、半影和石块纹理，检查画面不会被整个染成一片亮色。
3. 在台阶、凹槽里放灯，换视角检查终点附近的阴影是否稳定。
4. 用铁/橡木活板门在光源周围搭外壳，外壳与受光地面留出距离，观察孔洞光斑；参考档可见淡空气散射，流畅档保留表面投影。

比较 FPS 时保持世界、位置、时间、天气、分辨率、视距、曝光、VSync 和帧率上限一致。参考图 59–61 FPS 可能受帧率上限影响，不能直接当成显卡计算耗时的基线。

## 范围

仍是局部网格、阴影图与屏幕深度结合的软件光追；局部捕获为相机中心 64³ 格，每图块最多 4 灯、全场最多 256 灯。孔洞网格来自原版模型和纹理，自定义资源包几何需要重新生成。玻璃复杂内部多层折射和聚焦焦散、完整屏幕外反射、完整路径追踪尚未实现。新增体积光每像素只查询选中的最近一盏局部灯，密集灯群和快速移动仍需客户端检查。Voxy / Distant Horizons 专用接口未做本轮验收。

实现时序依据 [Iris 程序顺序](https://shaders.properties/current/reference/programs/overview/)，性能计时依据 [Khronos ARB_timer_query](https://github.com/KhronosGroup/OpenGL-Registry/blob/main/extensions/ARB/ARB_timer_query.txt)。
