# Revelation RT v8：多光源接缝与画质档位

目标：Minecraft 1.21.1 Fabric / Iris 1.8.14-beta.1。2026-10-27。

## 使用

选择 `Revelation-RT-v8-Quality.zip`，进入「光影设置」，使用首页左上角的画质选择器。

| 档位 | 用途 |
| --- | --- |
| 原版默认 | 保留原始 Revelation 的预设含义与传统光照参数，关闭本分支的新增光追功能 |
| 低 | 降低阴影、云、雾、反射质量，关闭间接全局光照 |
| 中 | 传统照明，减少采样与阴影距离 |
| 高 | 提高传统间接光、云、阴影和反射采样 |
| 极高 | 4096 阴影贴图、传统高质量间接光和反射 |
| 光线追踪（最高画质） | 原生分辨率局部灯光、16 次发光面采样、每像素 4 条间接光路径与 3 次反弹、4 次反射采样、染色玻璃透射、多光源体积散射 |

原包实际只有 `Default` 一个预设；低、中、高、极高是本版补充的常规画质档位。初次加载使用最高画质光追，适合先在问题场景中检查修复效果。各档位明确设置相同的一组质量参数，从光追切回普通档位后会关闭新增光追功能。材质包开关、颜色与曝光等独立偏好不由预设覆盖。手动修改受预设管理的选项后，Iris 可以显示「自定义」。

构建会在原实例的 `shaderpacks` 中新增本版文件，保留旧包。安装配置继承材质支持等独立偏好，不继承旧版的采样与档位参数。游戏画面和帧率由用户测试；最高档的实际负载取决于灯光数量、遮挡、分辨率和材质。

## 多灯裂纹的代码原因与修复

旧版每个 16×16 像素图块只保留最近的四盏灯，并且从少量深度样本决定图块的接收位置。密集灯阵中，相邻图块会突然换成另一组灯：同一面连续墙上的照明能量和阴影来源因此不连续。旧体积光只使用第一盏灯，也有类似切换。

v8 改为两个 128 位掩码，覆盖当前捕获的最多 256 盏灯。选择器用图块侧面的保守视锥平面与灯光影响球相交，覆盖全部深度、透明表面和雾；不再按接收位置排序截断。逐像素再按距离、朝向和有限影响半径剔除，累加所有有效灯光。图块纹理尺寸向下取整时，最后一个图块包含剩余边缘像素，避免非 16 整数倍分辨率漏灯。

这修复了已复现的灯光截断接缝；截图中是否还叠加其他游戏或材质问题，需要用户在同场景验收。

## 光照改进

- 使用发光面圆盘代理，分别在各采样位置计算遮挡、入射角、距离衰减和 GGX 高光。近处的面积光响应与半影更加一致。
- 以光源的绝对方块位置区分采样旋转；相邻灯具不再共享完全相同的采样方向，原子写入顺序变化也不会改变每盏灯的阴影采样。
- 多光源体积散射累加每盏候选灯，使用每段空气的指数消光，并计入光源到散射位置的空气衰减。空气透射率独立于灯光数量，避免最后一盏候选灯被剔除时空气突然消失。
- 保留局部空区域分层跳过、距离/朝向剔除与位扫描，减少无效遍历。光追最高档使用原生分辨率局部照明；高级设置仍可手动打开半分辨率计算。
- 修复低画质关闭全局光照后，下界传统光照分支引用主世界阳光变量的编译错误。

## 验证范围

`validation/build-v8.json` 汇总构建结果，并绑定当前 `shaders` 内容摘要。

- `compile-v8.json`：六档画质，以及材质、HDR、关闭玻璃、仅手持光源、关闭加速、半分辨率等相关分支的实际 GPU 编译/链接。
- `iris-metadata-v8.json`：当前已安装 Iris 的真实选项和预设解析器；六个独立档位、36 组切换、所有预设值合法、初始设置匹配光追档位、首页存在选择器。
- `dense-lights-v8.json`：4/9/36/129/256 灯与穷举 GPU 计算和独立平方反比/余弦参考对照，检查图块边界与非整倍数尾部、灯光顺序、16 次软阴影、多灯体积光加法。使用已交付 v7.1 的局部光照函数作为会丢失密集灯光能量的对照。
- `physical-probes-v8-regression.json`：孔洞遮挡、手持近墙、玻璃吸收/折射、选框与后期、可选半分辨率缓存等回归。

这是离线受控验证；未启动 Minecraft，不代表游戏效果、整帧 FPS 或所有模组兼容性已经验收。Distant Horizons / Voxy 注入接口未在本轮覆盖。

## 模型限制

局部遮挡和方块灯来自相机附近 64×64×64 的捕获网格，每帧最多 256 盏灯；超出捕获范围或容量的光源仍不在该模型内。发光面是圆盘代理，未完整表示每个灯具真实表面的出射分布。间接光与反射仍受屏幕深度和可见表面限制，不能查询所有屏外或被遮住的几何。这是软件光线追踪增强，不是调用硬件 RTX 的全场景路径追踪器。
