# Revelation RT v3 测试包

目标：Minecraft 1.21.1 Fabric，用户现有 Iris 1.8.14-beta.1 与 Sodium 0.8.13。原作者 HaringPro，Apache-2.0。本轮只构建交付，不进行游戏客户端实测。

将 `Revelation-RT-v3-LocalLights.zip` 放入实例的 `shaderpacks`，在 Iris 选中新包，先选“RT - 5060 日常”。无需解压。新文件名不会沿用 v2 同名选项文件；不要复制旧包的 `.zip.txt`。本次没有修改你的游戏配置、原包或存档。

改动：

- 恢复原版天空查找表的 `begin` 程序与既有清缓冲流程。玻璃 / 场景网格清空使用单独程序。
- 关闭存在数据依赖的 compute 并发，避免重投影缓存尚未完成就被 GI 读取。
- 新增局部不透明模型数据与放置光源列表。手持阴影改用模型形状查询，避免只依赖相机的一层深度。
- 从本机 Minecraft 1.21.1 模型生成 734 种方块、6048 条状态选择器的映射，保留整块、台阶、楼梯、围栏等轴对齐盒形差异；生成数据保留在包内，源码生成器位于工作区 `scripts/generate_rt_scene.py`。
- 捕获常用火把、灯笼、灵魂光源、红石火把、萤石、海晶灯等发光体；按 16×16 像素分块选择最多四个附近光源，并对有限光路计算遮挡和染色玻璃吸收。
- 已捕获局部光源附近抑制原版白色方块光的重复混合。太阳与局部玻璃光路统一按穿透厚度标定吸收，默认颜色浓度降至 0.65。
- 日常档调整为 1 路径、1 反弹、24 步、1 个粗糙反射样本；较高档位分别提升预算。原有云、太阳阴影和整体后期风格保留。

建议沿用之前的测试场景，观察：

1. 白天天空和地平线是否恢复；关闭玻璃着色后天空是否仍正常。
2. 放置火把 / 灯笼与白墙之间插入红、蓝玻璃，墙面是否得到对应颜色；移除玻璃后是否恢复。
3. 主副手拿火把绕石块和台阶移动，检查之前的黑条、阴影跳变；同时比较玻璃板与整块玻璃。
4. 固定位置、时间、天气、视距和窗口大小，记录日常档室外 / 洞内帧率。

边界：场景网格每轴 64 格，中心在相机附近，每帧依赖已加载且提交给阴影阶段的网格。没有提交面的完全封闭内部方块、范围外几何和未映射模组方块无法保证。盒形来自原版模型，旋转的非轴对齐元素、复杂特殊渲染、纹理镂空的细节不作为精确几何；资源包改变方块模型也不会自动改变这张预生成形状表。

最多捕获 256 个发光体，每个屏幕分块最多四个；光源密集区域可能丢失部分贡献。间接光与反射仍主要使用屏幕空间数据，完整折射 / 焦散、硬件 RTX 光追尚未实现。旧版参数“手持阴影追踪步数 / 求交厚度”不再控制新的模型阴影；新流程按实际盒形相交，手持光源半径仍可控制固定软阴影采样。

本次通过的检查以随包的 `validation/build-v3.json` 为准。编译与 ZIP 完整性通过仅证明这些构建步骤成功，不代表游戏中效果或 FPS 已通过验收。此前 v2 的 GPU 行为测试报告不作为 v3 验收结果。
